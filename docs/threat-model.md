# Модель угроз и границы 0.1

## Защищаемые данные

RAW-мысли, напоминания, локальная очередь и файлы Obsidian. Приоритет — отсутствие скрытого overwrite и возможность восстановить оригинал независимо от AI.

| Риск | Реализованная мера |
| --- | --- |
| Сеть или сервер недоступны | Транзакционная IndexedDB, очередь с retry, экспорт без сервера |
| Разрыв между commit и ACK | UUID/operationId, квитанции, повторяемые события и файлы |
| Ошибка записи журнала | Транзакция RAW + event, rollback |
| Конкурентная правка напоминания | Optimistic version, 409, сохранённый конфликт и копия |
| Попытка изменить RAW | Строгая схема POST, сравнение содержимого UUID, SQL-триггеры |
| Изменённый Markdown | Отдельная RAW-копия, исходный файл не заменяется |
| Path traversal / junction | Проверка UUID, разрешённых сегментов, lstat и realpath |
| Утечка credentials в frontend | Нет встроенных токенов; HttpOnly-cookie; device/session hash на сервере |
| Потерянное устройство | Revoke устройства и его сессий |
| Cross-origin запись | Проверка Origin, SameSite Strict, CORS по WEB_ORIGIN |
| DNS rebinding локального dev API | Разрешены loopback Host; dev listener не открывается в сеть |
| Переполнение запроса | Ограничение тела 512 КБ, длины полей, базовый rate limit |
| Приватные тексты в логах | Только тип/маршрут операции и имя ошибки |
| Утечка Obsidian settings | Агент не сканирует .obsidian и не выгружает vault |

## Требования к размещению

Внешний доступ — только через HTTPS. Node listener размещается за TLS proxy. Production требует AUTH_REQUIRED и HTTPS WEB_ORIGIN, сессии Secure/HttpOnly/SameSite. Ограничение запросов встроено в процесс; для внешнего размещения дополните его лимитами reverse proxy. Токены выдаёт оператор локальной CLI; удалённого открытого enrollment API нет.

Токен выдачи устройства многоразовый до revoke; «показан один раз» относится к CLI, а не к сроку действия. Первичный токен в браузере не сохраняется. .env исключён из контроля версий. Полный диск, экспорт и backup содержат незашифрованные личные записи, поэтому права доступа и шифрование устройства остаются обязанностью среды размещения.

## Не покрыто этой версией

Многопользовательская изоляция, E2EE, отзыв уже скачанных заметок с утерянного устройства, автоматический retention, постоянный push scheduler, PostgreSQL failover, совместная работа и удалённое зеркало vault. Не обещается защита от администратора ОС/сервера, вредоносного расширения браузера, изменения vault злонамеренным процессом в момент файловой операции или ручной очистки IndexedDB. При падении диска/потере компьютера нужен отдельный backup.

Проверки symlink защищают от заранее существующих ссылок, но не устраняют все TOCTOU-сценарии злонамеренного локального процесса. Агент рассчитан на доверенное локальное хранилище и один процесс записи. RAW остаётся на сервере даже после ACK и удаления Markdown пользователем.
