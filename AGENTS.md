# Инструкции для агента

Перед любой работой прочитайте [PREFERENCES.md](PREFERENCES.md) и следуйте ему.

Obsidian-хранилище — корень этого репозитория. `README.md` обязательно хранится внутри него. Поддерживайте в этом хранилище актуальность `README.md`, `CHANGELOG.md`, `PROJECT.md` и `STRUCTURED_IDEAS.md`.

Не изменяйте `BUGS.md` и `HANDWRITTEN_IDEAS.md`: их ведёт пользователь. Идеи из исходного файла можно отражать в `STRUCTURED_IDEAS.md`, не переписывая оригинал.

Основная продуктовая спецификация: [VAULT_TERMINAL_AGENT_SPEC.md](VAULT_TERMINAL_AGENT_SPEC.md). При конфликте приоритетов сохранность пользовательских данных важнее скорости и удобства.
